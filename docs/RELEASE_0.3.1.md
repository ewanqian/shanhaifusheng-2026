## 本轮修复

1. 山脉源网格约 99.98% 顶点法线朝下。倒置并启用单面渲染后，主体被剔除；修正新版副本的三角形绕序、法线和切线手性。按用户最新要求，山体材质双面可见，石头保持单面。几何与内嵌纹理精度不变。
2. 模型下载与音乐解码使用分阶段进度条。完成前禁用开始、跳幕、山脉预览和头显进入，避免在半载入状态操作。
3. 结束时显示头显内的重新体验、作品档案、退出空间。结束后普通捏合或扳机默认重播；指向按钮可选其他操作。退出 XR 后清理声音源、停留状态和时间进度。
4. 三段配乐循环：入场/回归、石场、悬山。每段从已有配乐摘取 32 秒，经 4 秒头尾等功率交叠，导出 28 秒 PCM 循环。章节间 4 秒音量渐变，停留时音乐持续循环；重播替换旧音源，保留静音设置。
5. “准备离线”按钮缓存本版本的网页、三个 GLB、三段音乐及专题图片。缓存隔离在 `versions/v0.3.1/`，不控制旧版页面。

## 音乐说明

本次使用原配乐已导出的前 115 秒素材，不改动 41 分钟原文件。选段起点为 5、38、72 秒。此为技术衔接试剪，尚未完成作者试听确认，不能当作正式演出音乐定稿。

循环源使用 [AudioBufferSourceNode.loop](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loop)，开始或进入 XR 的用户操作激活 [AudioContext.resume](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume)。场景停留不会暂停音频时钟。

## 验证

- 构建、JS 语法检查通过；7 项单元测试通过。
- IWER Quest 3 模拟运行完整 90 秒，观察到全部 5 幕、12 块石头、4 张阅读图片。
- 模拟 VR 中音频 context 为 running，三段均解码；结束后音量归零。扳机释放可重播。
- 停留验证：章节时间固定在 77.4208 秒，悬山配乐继续运行。退出 XR 后音源数量变为 0。
- 本地浏览器模拟断网后，刷新场域成功；专题 8 张图片全部加载。已恢复测试网络。
- 真实 Quest 的帧率、双面山体效果、手追踪按钮命中、MR 透视与现场听感仍需真机确认。

## 离线使用

1. 联网打开 0.3.1，点击“准备离线”。
2. 等待显示“离线已就绪”，再关闭网络。
3. 刷新同一版本网址，检查模型、音乐和专题原图完整出现。
4. 展前在真实 Quest 做一次完整断网重启验证。浏览器清理数据或系统回收缓存后，需要重新准备。

这不是 APK，也不保证从未联网的设备首次启动可用。APK 包装与根域 Digital Asset Links 保留为后续任务。
